01 — Selected work

Things I've been building

Each card follows the same arc: the problem worth solving, how I approached it, and what it runs on.

  1. RustIn progress

    goh

    Problem
    Terminal autocomplete tools are either heavy, cloud-tied, or stuck in one terminal. I wanted one that's light, private, and lives in the terminal you already use.
    Approach
    A daemon plus popup that suggests subcommands, options and arguments in context. The popup inherits your terminal's colors; where the OS won't allow an overlay, it falls back to inline hints instead of faking support.
    Built with
    Rust · IPC schema · shell integration · design system & prototype first
    View repository

  2. TypeScriptIn progress

    Mailbox

    Problem
    Several inboxes, each full of noise. I wanted one inbox for every account, with zero clutter.
    Approach
    A mailbox that runs entirely on Cloudflare Workers: custom-domain addresses receive through Email Routing and send from Workers, with threading, full-text search, rules, scheduled and undo send, and AI thread briefs and draft replies.
    Built with
    Cloudflare Workers · D1 · R2 · Durable Objects · Workers AI · TanStack Start

  3. GoTypeScript

    Genlio

    Problem
    Shopee affiliates spend hours writing captions and posting the same products by hand to Facebook Pages and Instagram.
    Approach
    Paste a product link, pick an opening hook, edit the AI-drafted caption and choose a time. Genlio schedules the post and tracks clicks through its own links.
    Built with
    Go · PostgreSQL · TanStack Start · Astro · Cloudflare Workers & Queues · Grafana
    Visit genlio.co
